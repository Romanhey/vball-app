### Folder that contains bugs (only for VBALL.Mobile) should be fixed in format

## KeyboardOverlapAuthScreen
## what actually happans
When focusing on input fields on the authentication screen (login/registration), the on-screen keyboard appears and overlaps important UI elements such as input fields and action buttons (e.g., Login/Register). This makes them partially or completely inaccessible.
## what should do happends
The UI should properly adjust when the keyboard appears so that all input fields and action buttons remain visible and accessible. The user should be able to interact with all elements without obstruction.
